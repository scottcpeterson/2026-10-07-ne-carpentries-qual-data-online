# Northeast Carpentries Qualitative Data Workshop Series

This repository is for an October 2026 Northeast Carpentries qualitative data workshop series. This workshop series is put on by members of the Northeast Carpentries Community happening Wednesday afternoons in October that aims to teach participants basic concepts, skills, and two tools for working with qualitative data: Taguette and QualCoder. These are free online workshops designed for anyone using or planning to use qualitative data in their research. No experience with Taguette or QualCoder is required.

WORKSHOP SCHEDULE & TOPICS
- October 7, 2-3pm:  Introduction to working with qualitative data
  - This introductory workshop provides an overview of qualitative methodology and data interpretation. Participants will explore core practices for gathering non-numerical data (such as semi-structured interviews and focus groups) and practical techniques for thematic analysis and coding.
- October 14, 2-3:30pm: [Open qualitative research with Taguette](https://librarycarpentry.github.io/lc-qualitative-taguette/instructor/index.html)
  - Learners will practice working with secondary qualitative data from the Qualitative Data Repository (QDR) in the free software Taguette and discuss the options and limitations for open research with proprietary qualitative analysis packages, including options for sharing both source data and coded analysis projects.
- October 21, 2-4:30pm: [Open qualitative research with QualCoder](https://librarycarpentry.github.io/lc-qualitative-qualcoder/instructor/index.html)
  - Learn to use QualCoder, a free and open-source qualitative coding and data analysis tool. This workshop will provide introductory training in the principles of deductive and inductive qualitative coding through practice with QualCoder.
